# start-dsh

DSH（DeepSeek Harness）Web 界面一键启动脚本（Windows PowerShell）。

本脚本等价于执行官网命令 `npx @deepseek-ai/dsh web`，并在此基础上提供：

- **高峰时段检查**：北京时间 9:00–12:00、14:00–18:00（工作日）启动前提示确认（y/n）
- **周末直接进入**：北京时间周六、周日全天不区分峰谷时段，无需提示直接启动
- **端口占用检测**：DSH 已在运行时只打开浏览器，不重复启动
- **自动打开浏览器**：端口就绪后自动访问
- **前台 / 后台** 两种运行方式

## 环境要求

- Windows + PowerShell 5.1 及以上
- Node.js（提供 `npx`；或 PATH 中已安装 `dsh`）

## 快速开始

```powershell
.\start-dsh.ps1
```

非高峰时段直接启动；高峰时段会提示：

```text
当前为高峰时段（北京时间 9:00-12:00、14:00-18:00），是否继续进入？请输入 y/n
```

输入 `y`/`Y` 继续启动，输入 `n`/`N` 取消。

周末（北京时间周六、周日）全天不再区分峰谷时段，直接进入，不会出现上述提示。

## 参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-Port` | 3080 | 监听端口，传 0 表示系统自动分配 |
| `-BindHost` | 127.0.0.1 | 绑定地址，仅本机可访问（安全默认值） |
| `-TrustedHost` | （空） | 额外信任的浏览器来源，对应 dsh 的 `--trusted-host`（host 或 host:port） |
| `-NoBrowser` | — | 启动后不自动打开浏览器 |
| `-Background` | — | 后台运行，日志写入 `%USERPROFILE%\.dsh\logs` |

## 示例

```powershell
# 默认启动（前端 http://127.0.0.1:3080）
.\start-dsh.ps1

# 指定端口，且不自动打开浏览器
.\start-dsh.ps1 -Port 8080 -NoBrowser

# 后台启动
.\start-dsh.ps1 -Background
```

后台模式会打印 PID、日志路径与停止命令：

```powershell
taskkill /PID <pid> /T /F
```

## 实现细节

- 北京时间以 UTC+8 计算，与本机时区无关（中国无夏令时）。
- 高峰时段为 9:00–12:00 与 14:00–18:00（含起点、不含终点），仅工作日生效。
- 自 2026-08-23（周日）00:00 起，DeepSeek 周末（周六、周日）全天不区分峰谷时段，脚本直接进入、不进行高峰时段询问。
- 若目标端口已有 DSH 实例在运行，脚本直接打开浏览器并退出，不再提示。
- 工作目录固定为脚本所在目录，DSH 会话按该目录归类。
